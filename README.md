# Backend Quest

Курс о том, как запускать и вести бэкенд-проект вместе с агентом.

Код в этом курсе пишет агент. Ты учишься тому, что делает человек: понимать, как устроен веб, настраивать проект и агента, формулировать задачи и принимать результат по диффу и тестам.

Принципы одинаковы во всех языках, поэтому каждая тема показана сразу на двух: PHP и Python. Сравнивай их: то, что совпадает, и есть принцип.

## Чему ты научишься

- понимать, как клиент общается с сервером по HTTP;
- отличать валидацию, фильтрацию и экранирование и знать, где какая нужна;
- понимать, почему пароль хранится хэшем, и чем вход отличается от прав доступа;
- вести проект в git: ветки, коммиты, merge request;
- настраивать агента: `AGENTS.md`, правила, проверки;
- ставить агенту задачу так, чтобы получить то, что нужно;
- читать дифф, запускать тесты и находить дефекты.

## Как устроен курс

1. Теория по верхам: короткие уроки без большого кода.
2. Проект 1: «Регистрация и вход». Минимальный завершённый сайт.
3. Следующие проекты наращивают сайт: профиль, роли, админ, база данных.
4. Архитектура (MVC) и фреймворки.
5. Свой проект с нуля.
