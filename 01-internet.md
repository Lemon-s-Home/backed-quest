# 01. Что происходит, когда открываешь гугл

Ты пишешь `google.com`, жмёшь Enter, и через секунду перед тобой страница. За эту секунду случается пять вещей. Любой сайт, который напишет агент, живёт внутри этих пяти вещей, поэтому пройдём их по одной и каждую потрогаем руками.

## Шаг 1. Имя превращается в адрес

Компьютеры не понимают `google.com`. У каждого компьютера в сети есть числовой адрес, он называется IP, например `142.250.130.139`. Имена придуманы для людей, числа — для машин.

Переводит одно в другое DNS. Это телефонная книга интернета: даёшь имя, получаешь адрес. Спросим её сами, на двух языках.

PHP, файл `dns.php`:

```php
<?php

declare(strict_types=1);

echo gethostbyname('google.com') . "\n";
```

Python, файл `dns.py`:

```python
import socket

print(socket.gethostbyname("google.com"))
```

Запуск:

```bash
php dns.php
python3 dns.py
```

Оба напечатают адрес. Он может не совпасть с моим и даже у PHP и Python отличаться друг от друга: у Google тысячи серверов, и DNS раздаёт то один адрес, то другой.

Одно имя особенное: `localhost` всегда значит «этот же компьютер», его адрес `127.0.0.1`. Свой первый сервер мы запустим именно там.

## Шаг 2. Адрес и порт

Адрес — это дом, порт — номер двери. На одном компьютере живёт много программ, и каждая слушает свою дверь. Две самые частые:

- `80` — обычный сайт (HTTP);
- `443` — сайт с замочком (HTTPS), то есть тот же разговор, но шифрованный.

Когда ты пишешь `https://`, браузер сам стучится в дверь `443`. А если ты пишешь `127.0.0.1:8000`, то `8000` — это и есть порт.

## Шаг 3. Запрос

Соединение есть. Браузер присылает короткое письмо: «дай мне главную страницу». Это запрос. Тот, кто спрашивает, называется клиентом.

## Шаг 4. Ответ

Сервер, то есть программа Google на другом конце, читает письмо и отвечает. В ответе есть код («всё хорошо», «такой страницы нет», «мы переехали») и сама страница.

Клиент всегда говорит первым. Сервер сам ничего не присылает, он только отвечает.

## Шаг 5. Браузер рисует

Страница приходит как текст с разметкой. Браузер превращает его в картинку с кнопками. К самому разговору это уже не относится: интернет доставил текст, остальное делает браузер.

## Все пять шагов в одном ответе

Браузер всё это делает молча. Но есть клиент, который показывает каждый шаг. Он называется `curl`:

```bash
curl -v http://google.com/
```

Вот важные строки его вывода, я пометил шаги:

```text
* Host google.com:80 was resolved.                     <- шаг 1: имя стало адресом
* IPv4: 142.250.130.139, 142.250.130.113, ...
*   Trying 142.250.130.139:80...                       <- шаг 2: стучимся в дверь 80
* Connected to google.com (142.250.130.139) port 80
> GET / HTTP/1.1                                       <- шаг 3: наш запрос
> Host: google.com
<
< HTTP/1.1 301 Moved Permanently                       <- шаг 4: ответ
< Location: http://www.google.com/
```

Строки с `>` — это то, что отправил ты. Строки с `<` — то, что пришло в ответ.

Обрати внимание на ответ: `301 Moved Permanently`. Google отвечает: «мы переехали на `www.google.com`». Браузер молча идёт по новому адресу, поэтому ты никогда этого не замечаешь. Зато `curl` ничего не скрывает.

Именно поэтому дальше всё курсом проверяется через `curl`: он показывает, что сервер ответил на самом деле, а не что тебе пересказали.

## Шпаргалка

- Имя (`google.com`) превращается в IP-адрес через DNS.
- Адрес — это дом, порт — это дверь. `80` — HTTP, `443` — HTTPS.
- Клиент спрашивает, сервер отвечает. Первым всегда говорит клиент.
- Ответ состоит из кода и тела. Браузер рисует тело.
- `localhost` и `127.0.0.1` — твой собственный компьютер.
- `curl -v` показывает весь разговор: строки с `>` ушли от тебя, строки с `<` пришли в ответ.

## Напоследок

1. Самый первый сайт в мире до сих пор открывается. Он лежит на `info.cern.ch`: просто текст и ссылки, без картинок. Проверь сам: `curl -i http://info.cern.ch/`.

2. Адресов вида `142.250.130.139` всего около 4,3 миллиарда. Это меньше, чем людей на Земле. Свободные закончились ещё в 2011 году, и поэтому появился новый формат адресов (IPv6), а старые адреса теперь делят между собой телефоны, дома и целые офисы.

3. Почти весь трафик между континентами идёт не через спутники, а по кабелям на дне океана. Такой кабель примерно как садовый шланг. Когда ты открываешь сайт на другом конце света, ответ, скорее всего, приплывает по дну.

## Практика

### 1.1. Спроси DNS

Запусти оба скрипта из урока для трёх имён: `google.com`, `localhost` и `info.cern.ch`. Запиши адреса. Совпали ли они у PHP и у Python? Если нет, объясни одной фразой почему.

### 1.2. Найди пять шагов

Выполни `curl -v http://google.com/` и найди в выводе строки, которые относятся к шагам 1–4. Выпиши по одной строке на шаг. Потом выполни `curl -v https://www.google.com/` и найди два отличия: какой порт и какие новые строки появились. Подсказка про них есть в словах «замочек» и «шифрованный».
